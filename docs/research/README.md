## 1. Agent-UI kits (closest peers)
| Reference | What to learn | Licence |
|---|---|---|

| [BoardUI](https://www.boardui.com/) | One `waiting` flag drives composer glow + thinking row + controls; composer border light | Free MIT tier / Pro |
| [coss ui](https://coss.com/ui) | Composer API (@ and / triggers, Enter-to-send, disable-send, adaptive rows) | MIT |
| [HextaUI](https://hextaui.com/) | Stop / retry / versions, no-jump thread | MIT + Pro |
| [Astryx (Meta)](https://astryx.atmeta.com/components) | Chat send button, tool calls, tokenized text; Playground with click-to-edit | Open source (licence unconfirmed) |
| [Libraries.dev](https://libraries.dev/) | Thinking orbs (9 states), voice ring, border beam, size-specific tuning; paid Studio over free runtime | Packages MIT |
| [Wensity UI agentic](https://ui.wensity.com/components/category/agentic-ai-interfaces) | Steps array with per-tool verbs and renderers | — |
| affectUI, Arc UI, Bencho | Catalog depth, Pro presentation, prompt-copy, MCP | Paid / study only |

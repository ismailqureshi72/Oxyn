# Licensing & attribution

Oxyn's open core is MIT. We study a lot of paid and restrictively licensed work; we copy none of it.

## Rules
1. **Port code only from MIT or Apache-2.0 sources**, keep their notice in the file header and list
   them in `THIRD_PARTY_NOTICES.md` (created with the first port).
2. **Study-only** (no code, no assets, no verbatim copy): paid kits and Pro tiers, AGPL (e.g. Warp),
   GPL, custom or unclear licences, and sites whose terms forbid building a competing kit.
3. **Ideas are free, expression isn't.** Re-implement behaviour from our own spec and timing tables.
4. **Verb lists and copy are written in-house.**
5. Screenshots and videos used for study stay local (`/captures`, git-ignored) — never committed.

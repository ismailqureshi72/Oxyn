# Arc UI (uiarc.dev) → Oxyn parity inventory

Built 2026-11-12 from a live read of uiarc.dev. Purpose: every Arc item Oxyn must match, what it does, its states, controls and motion, where it lands in Oxyn, and how Oxyn goes further. Behaviour only: no Arc source was opened or copied (Pro source is token-gated and was not touched; free source was not read either).

**How it was read.** Every item page (389 URLs = 377 sidebar rows + 12 variant pages) was fetched over HTTP and returned 200, as did the site pages listed in the Summary. Per-item facts (purpose, props, keyboard, motion) come from Arc's per-item docs as published in `https://uiarc.dev/llms-full.txt` (the same text as each page's sections) and `https://uiarc.dev/r/catalog.json`; the sidebar structure, groups, Free/Pro badges and New tags come from the server-rendered page HTML. Earlier notes (`research/12-arc-catalog.md`, `12-arc-deep-dives.md`, `12-arc-site-design.md`) were used for the site chrome and checked against today's pages; corrections are noted below.

**Corrections to the earlier notes.** Blocks now has 136 sidebar rows (was 134): new since the first catalog are KPI drilldown, Agent run, Agent tasks, Profile page, Import wizard (New), Release readiness and Month calendar (New); Developer is 7 and Projects 11. Totals per Arc: 244 components (121 free / 123 Pro) + 143 blocks (22 free / 121 Pro) = 387. Login (5 variants) and Sidebar (4 variants) are family pages; Theme switcher has 3 transition sub-pages (Eclipse, Split, Rise). Pricing is now $149/yr, $249 lifetime, Team $799 once or $449/yr for 10 people. A "Saved" feature (press S) and use-case sidebar search shipped 2026-11-11.

**Columns.**
- *Tier*: Free (MIT, public registry) or Pro (token-gated registry; preview still live for everyone).
- *States*: union values of state-like props (`status`, `phase`, `variant`…), boolean state flags, then `docs:` state words that appear in that item's own docs (hover, loading, error…). Interaction states that every Arc control has (hover only on fine pointers, keyboard-only focus ring, reduced-motion branch) are not repeated per row.
- *User controls*: every documented prop except plumbing (`className`, `children`, `id`, `name`, `ref`, `style`, `as`, aria-label). `(a/b/c)` = allowed values, `?` = boolean, `events:` = callbacks, `keys:` = keyboard bindings. Blocks marked *No props* are self-contained demos; their built-in controls are described.
- *Micro-interactions & timings*: the first two motion notes from the item's docs, then every explicit duration found (⏱) and which shared motion presets it uses. Arc presets: `snappy` (visualDuration 0.26, bounce 0), `smooth` (0.4, 0), `morph` (0.42, 0), `responsive` (stiffness 520 / damping 44), `gentle` (340 / 34); CSS `--duration-fast` 160ms, `--duration-standard` 240ms, `--duration-considered` 480ms; text shimmer 1.8s; status crossfade 100ms out / 160ms in from 2px.
- *Oxyn spec*: file in `/workspace/work/Oxyn/docs/specs/`. "(partial)" = the spec covers part of it and should be extended; NEW = no spec yet (batched in the Summary).
- *Oxyn plus*: 1–3 extra variants or user controls Oxyn should ship on top of parity. Agent-app angle first.
- 🆕 = tagged New in Arc's sidebar today.
